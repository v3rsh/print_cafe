Этот документ — главный «контракт безопасности» между ботом и бизнесом. Он отвечает на три вопроса: **когда** бот должен передать клиента человеку, **кому** именно, и **что бот точно не должен делать сам**. Эти правила пойдут прямо в системный промпт и в логику handoff.

- [ ] **Тираж больше N штук** (N = _____). Логика: «нужен индивидуальный расчёт».

### 3.3. По поведению клиента

- [ ] **Явная просьба позвать человека** («хочу с менеджером», «оператора», «человека»).

- [ ] **Молчание клиента больше X часов** после собранного брифа (X = _____) — менеджер дожимает.
- [ ] **VIP-клиент** (есть в стоп-листе по номеру / @nick / email) — сразу к менеджеру, минуя бота.

## 6. Что бот точно НЕ должен делать

Это «красные линии». Бот никогда их не пересекает — даже если клиент настойчиво просит. Отметьте, что оставить.

- [ ] **Не озвучивать финальную цену.** Может говорить только «примерно от X ₽» из прайса. Точная цена — только от менеджера.
- [ ] **Не давать скидки и не торговаться.** На просьбу «сделайте скидку» — звать менеджера.
- [ ] **Не обещать сроки без подтверждения менеджером.** Может говорить только стандартный диапазон из базы.
- [ ] **Не подтверждать заказ.** Заказ всегда подтверждает менеджер после расчёта и оплаты.
- [ ] **Не выставлять счёт и не присылать реквизиты.** Только менеджер.
- [ ] **Не согласовывать макет.** Принять файл и передать менеджеру.
- [ ] **Не отвечать на off-topic** (политика, религия, личные вопросы, спор о новостях, шутки не про печать).
- [ ] **Не использовать ненормативную лексику и сарказм** даже в ответ на провокацию.
- [ ] **Не озвучивать сведения о других клиентах** («у нас вчера был заказ от X»).
- [ ] **Не выдавать внутренние данные** (стоимость закупки, маржу, имена сотрудников, адрес склада, если он не публичный).
- [ ] **Не давать юридические, медицинские, финансовые советы.**
- [ ] **Не претендовать на то, что он — человек.** Если клиент спрашивает «ты бот?» — честный ответ: «Да, я ассистент. Если нужно — позову менеджера».
- [ ] **Не выдумывать акции, которых нет.**
- [ ] **Не отправлять ссылки, которые не из утверждённого списка** (сайт printcafe.ru, прайс, портфолио). Никаких «гугл, спроси у DeepSeek».

## 7. Что бот делает при handoff (для информации)

Чтобы вы понимали, как это будет выглядеть со стороны клиента и менеджера:

1. Клиент попадает под триггер передачи.
2. Бот пишет клиенту короткое подтверждение (например: «Понял! Передаю менеджеру, ответит в течение N минут в рабочее время»). Финальную формулировку согласуем по результату заполнения `06_tone_of_voice.md`.
3. В Wazzup24 диалог получает тег `human_needed` (или другой по согласованию).
4. Если подключена CRM — создаётся / обновляется сделка с собранным брифом.
5. Менеджер видит уведомление, открывает диалог, читает бриф, продолжает с того места, где остановился бот.
6. Бот **не возвращается** к клиенту автоматически после передачи (только если менеджер сам разрешит командой / тегом).
