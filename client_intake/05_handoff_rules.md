# Регламент передачи диалога оператору

**Статус: черновик аналитика, согласовать с заказчиком.**

Документ — главный «контракт безопасности» между ботом и бизнесом. Он отвечает на три вопроса: **когда** бот должен передать клиента человеку, **кому** именно, и **что бот точно не должен делать сам**.

Все значения ниже проставлены с учётом профиля Print Cafe (4 розничные точки в ТЦ Волгограда/Волжского, печать «здесь и сейчас» за 20 минут + оптовая линия). Любое поле заказчик может поменять — это стартовая конфигурация под запуск, не догма.

## 2. Что бот отвечает вне рабочих часов

Если клиент написал, когда менеджеров онлайн нет (например, в 23:30 или в 7 утра), бот:

1. Отвечает на содержательный вопрос, **на который может ответить сам** (часы работы, базовые цены, минимальный тираж, адреса, бесплатный макет).
2. Если нужен менеджер — отправляет короткое сообщение:

> _Сейчас наши магазины уже закрыты — мы работаем ежедневно с 10:00 до 22:00 (МСК). Я записал ваш вопрос: как только утром менеджер подключится, он сразу ответит здесь же. Если хотите, пока могу подсказать по продукции, ценам и срокам — спрашивайте._

3. **Не обещает конкретное время ответа** («ответят в течение 10 минут утром» — нет; правильно «как только подключится утром»).
4. Утром, когда менеджер подключается, бот **не дёргает клиента сам** — менеджер сам открывает диалог и продолжает.

## 3. Триггеры передачи оператору

Условные обозначения: **[x]** = триггер включён в стартовый набор, **[ ]** = по умолчанию выключен (с комментарием почему).

### 3.1. По объёму и сложности заказа

- [x] **Тираж больше 10 шт.** Логика: сайт сам говорит «внушительные скидки от 10 шт., оптовый прайс по запросу» — точная цена считается индивидуально, бот сам это не делает. Это **самый частый триггер по B2B-линии**.
- [x] **Сумма заказа предполагаемо > 10 000 ₽** (например, ≥ 30 кружек, ≥ 15 футболок, любой холст 84×60 и больше, оклейка транспорта, баннер от 5 м²). Логика: розничный квантум — низкий, всё крупнее требует расчёта.
- [x] **Нестандартный носитель / товар не из каталога** («напечатать на скейтборде, зонте, спецодежде, кепке, шоппере»). На сайте кепок и шопперов нет вообще — это значит, что бот точно не должен пытаться их «продать».
- [x] **Срочный заказ — менее 24 часов до дедлайна.** В рознице у Print Cafe 20 минут — это норма; срочность за пределами розницы (опт за день, флаг за день) — индивидуальный кейс.
- [x] **Заказ «под ключ»** — мерч с разработкой айдентики, упаковкой, сборкой комплектов.

### 3.2. По типу обращения

- [x] **Жалоба или претензия** (брак, опоздание, недовольство, «принт стирается»).
- [x] **Упоминание уже оформленного заказа** («где мой заказ», «когда отправите», «номер заказа №…»).
- [x] **Запрос на возврат / переделку.**
- [x] **Клиент просит скидку или индивидуальные условия.**
- [x] **Согласование макета** (клиент прислал файл — бот принимает, благодарит, передаёт менеджеру, **сам макет не правит и не утверждает**).
- [x] **Запрос договора / счёта / закрывающих документов** (УПД, акт, КП с печатью и подписью).
- [x] **Запрос на тендер / 44-ФЗ / 223-ФЗ / NDA.**
- [x] **Запрос на доставку в другой город / за рубеж** — на сайте только «100% предоплата, отправим почтой», тарифов нет, рассчитывает менеджер.

### 3.3. По поведению клиента

- [x] **Явная просьба позвать человека** («хочу с менеджером», «оператора», «человека», «живого», «не бота»).
- [x] **Бот два ответа подряд не попал** (клиент пишет «нет, не то», «вы меня не поняли», «опять не так»).
- [x] **Бриф собран** — пора передавать менеджеру для точного расчёта. Это **основной позитивный триггер**: бот сделал свою работу, передал.
- [x] **Молчание клиента больше 24 часов** после собранного брифа — менеджер сам дожимает, бот не пингует.
- [x] **VIP-клиент** (есть в стоп-листе по номеру / @nick / email) — сразу к менеджеру, минуя бота.
- [x] **Эмоциональный негатив**: мат, агрессия, оскорбления — мгновенный handoff, бот не пытается «успокоить».

### 3.4. Свои триггеры (специфика Print Cafe)

- [x] **Корпоративный мерч / B2B (упоминание ИНН, юрлица, ООО, ИП, «нужен счёт», «надо договор», «реквизиты для счёта»)** — менеджер с B2B-компетенцией.
- [x] **Иногородний клиент с просьбой об отправке** («я из Питера», «доставите в Краснодар») — нужен расчёт почтового тарифа и предоплаты.
- [x] **Вопрос про оптовый прайс-лист** — бот предлагает заполнить форму на сайте или передаёт менеджеру.

## 6. Что бот точно НЕ должен делать

Это «красные линии». Бот никогда их не пересекает — даже если клиент настойчиво просит. **Все пункты включены в стартовый набор.**

- [x] **Не озвучивать финальную цену.** Может говорить только «примерно от X ₽» из прайса. Точную цену под конкретный заказ всегда выдаёт менеджер. Эта линия отдельно важна для опта — там сайт сам пишет «считаем индивидуально».
- [x] **Не давать скидки и не торговаться.** На «сделайте скидку» — фиксирует пожелание и зовёт менеджера.
- [x] **Не обещать сроки** за пределами того, что прямо написано на сайте (розница 20 мин, холст 1 день, интерьерная от 2 ч, флаги 3–5 дней). Для опта, корпоратива, нестандартных позиций — только «менеджер уточнит».
- [x] **Не подтверждать заказ** как принятый в работу. Заказ всегда подтверждает менеджер после расчёта и оплаты.
- [x] **Не выставлять счёт и не присылать реквизиты.** Только менеджер.
- [x] **Не согласовывать макет.** Принять файл, поблагодарить, сказать «передаю в работу менеджеру» — и передать. Никаких «выглядит отлично, печатаем!».
- [x] **Не отвечать на off-topic** (политика, религия, личные вопросы, обсуждение конкурентов, спор о новостях, шутки не про печать). Вежливый возврат к теме: «Я могу помочь по продукции и заказам Print Cafe. Что-нибудь по этому подсказать?»
- [x] **Не использовать ненормативную лексику, сарказм и провокации** — даже в ответ на агрессию клиента. На мат — мгновенный handoff без эмоций.
- [x] **Не озвучивать сведения о других клиентах** («у нас вчера был заказ от Х»), даже если они в разделе «Нам доверяют» на сайте.
- [x] **Не выдавать внутренние данные**: стоимость закупки, маржу, имена и графики сотрудников, адрес склада/производства за пределами адресов магазинов, технические подробности оборудования за пределами того, что есть на сайте (Roland — упомянуто, остальное — нет).
- [x] **Не давать юридические, медицинские, финансовые советы.** Даже если клиент спрашивает «можно ли мне этот принт по закону» — «не подскажу, это не наша компетенция, в случае спорной символики — позову менеджера».
- [x] **Не претендовать на то, что он — человек.** На «ты бот?» — честный ответ: «Да, я цифровой ассистент Print Cafe. На простые вопросы отвечу сам, если нужно — позову менеджера».
- [x] **Не выдумывать акции, бонусы и спецпредложения**, которых нет на сайте. На сайте сейчас публично есть «холст со скидкой 50%» и «скидки от 10 шт.» — больше ничего не озвучивает.
- [x] **Не отправлять внешние ссылки**, кроме утверждённого белого списка: `printcafe34.ru`, страницы из этого домена, политика конфиденциальности (`politics_printcafe34.pdf`), email `printcafe@ya.ru` и `printcafe.tt@ya.ru`. Никаких «погуглите», «вот ссылка на конкурента», «вот ссылка на DeepSeek», «вот видео на Youtube».
- [x] **Не угадывать наличие конкретного цвета, размера или модели в конкретной точке** — на сайте этих данных нет, остатки в реальном времени бот не видит. На прямой вопрос «у вас сейчас есть оверсайз L в чёрном в Акварели?» — «уточнит менеджер / позвоните в магазин по +7 (8442) 50-47-87».

## 7. Что бот делает при handoff (для информации)

Чтобы заказчик понимал, как handoff выглядит со стороны клиента и менеджера:

1. Клиент попадает под триггер из раздела 3 — например, спросил «а сколько 100 футболок?».
2. Бот собирает по разделу 5 минимальный бриф (тип, тираж, размеры, есть ли макет, дедлайн, контакт, удобный ТЦ).
3. Бот пишет клиенту короткое подтверждение:

   > _Понял, передаю заявку менеджеру — он сделает точный расчёт под объём и ответит здесь же в течение рабочего дня (10:00–22:00). Пока ничего больше делать не нужно._

4. В Wazzup24 диалог получает тег `human_needed` (или другое имя по согласованию). Если подключена CRM — создаётся / обновляется сделка с уже собранным брифом.
5. Менеджер открывает диалог, читает сводку, продолжает с того места, где остановился бот.
6. **Бот не возвращается к клиенту автоматически после передачи.** Он снова берёт диалог только если менеджер явной командой / тегом разрешит (например, после закрытия сделки).

3. Один общий канал в Wazzup24 или нужны выделенные для B2B / опта (раздел 4).

5. Подтверждение списка «красных линий», особенно про скидки и сроки.
6. Согласие с минимальным брифом и обязательными полями (раздел 5).
7. Контакт ответственного менеджера для пилотного запуска.
