# FAQ Print Cafe — шаблон для заполнения

Это типовые вопросы, которые задают клиенты в Wazzup24. Заполните ответы как в реальной переписке — короткими, человеческими формулировками. Бот на этой основе будет отвечать тем же стилем.

**Как заполнять:**

- Если на какой-то вопрос отвечать не нужно (всегда зовите менеджера) — оставьте поле пустым и напишите рядом `→ оператору`.
- Если ответов несколько (например, разные варианты доставки) — давайте все, бот выберет нужный по контексту.
- Можно (и нужно) добавлять свои вопросы — в конце каждого раздела есть пустые слоты.
- В тексте можно писать прайс-цифрами, ссылки, адреса — это нормально.
