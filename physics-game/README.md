# ТермоКвест — физика 8 класс

Браузерная викторина по первым трём темам курса физики 8 класса:

1. Температура и тепловое движение
2. Внутренняя энергия
3. Способы изменения внутренней энергии

## Как открыть

Открой `index.html` в браузере или запусти локальный сервер:

```bash
cd physics-game
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем перейди на http://127.0.0.1:8765
